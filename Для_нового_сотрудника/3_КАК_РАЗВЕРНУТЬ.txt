КАК РАЗВЕРНУТЬ ПРОЕКТ У СЕБЯ
=============================

Нужен установленный Python 3 и Git.
Все команды выполняются в терминале, в папке проекта.


ШАГ 1. Скачать код
  git clone https://github.com/LedenevAleksei/planfact-dashboard.git
  cd planfact-dashboard

ШАГ 2. Установить зависимости (библиотеки)
  pip install -r requirements.txt

ШАГ 3. Создать файл .env со своим ключом
  cp .env.example .env
  Затем открыть .env в любом редакторе и вписать:
    - PLANFACT_API_KEY  — свой ключ ПланФакта (взять в ПланФакте: Настройки → API)
    - DASH_USER / DASH_PASS — придумать логин и пароль для входа в дашборд
  (Supabase и Cloudflare — по желанию, для общего хранилища и домена. Без них работает локально.)

ШАГ 4. Подтянуть реальные цифры и собрать дашборд
  python3 dashboard/fetch_data.py    (выгрузка из ПланФакта — ТОЛЬКО чтение)
  python3 dashboard/build.py         (сборка index.html с реальными данными)

ШАГ 5. Открыть дашборд
  Локально:  python3 app.py   → открыть в браузере http://localhost:8000
  (или открыть файл dashboard/index.html напрямую двойным кликом)


ХОСТИНГ (по желанию, чтобы дашборд был доступен по ссылке 24/7)
  Проект уже настроен под Railway (файлы Procfile, railway.toml).
  Кратко: создать проект на railway.app из этого репозитория,
  задать те же переменные окружения (ключ, логин, пароль) в панели Railway.
  Подробности — в файле DEPLOY.md внутри репозитория.


ГЛАВНОЕ ПРАВИЛО: ключ ПланФакта — только для ЧТЕНИЯ.
Дашборд ничего не меняет в ПланФакте. Ключ хранится только в .env, никуда не отправляется.
