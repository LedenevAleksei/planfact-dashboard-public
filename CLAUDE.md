# Инструкции для ИИ-ассистента (Claude Code) в этом проекте

Этот файл читается ассистентом при работе в папке проекта. Он задаёт правила и переживает передачу проекта другому человеку.

## 🔴 Правило №1 — API ПланФакта только для чтения
Никогда не создавать, не изменять и не удалять данные через API (никаких write `POST/PUT/DELETE`, меняющих сущности: операции, справочники, бюджеты). Отчётные `POST` (`/api/v2/reports/*`, `/dashboards/*`, `/operations/list`) — это чтение, они разрешены. Все находки выдавать как отчёты и рекомендации; исправления пользователь делает вручную в интерфейсе ПланФакта.

## 🔑 Правило №2 — ключ
- API-ключ берётся ТОЛЬКО из `.env` (переменная `PLANFACT_API_KEY`).
- Никогда не выводить ключ в чат, логи, команды, файлы отчётов, коммиты.
- У каждого сотрудника — свой ключ. При передаче проекта новый человек кладёт свой ключ в `.env` (файл в `.gitignore`, не передаётся).
- Если `.env` нет или ключ пустой — остановиться и попросить создать `.env` по образцу `.env.example`. Не просить ключ в чат.

## 📝 Правило №3 — обновлять документацию после каждой итерации
После каждой значимой итерации ОБНОВЛЯТЬ:
- [CHANGELOG.md](CHANGELOG.md) — добавить запись (дата, что сделано).
- [ROADMAP.md](ROADMAP.md) — отметить выполненное, скорректировать план.
- [ARCHITECTURE.md](ARCHITECTURE.md) / [DECISIONS.md](DECISIONS.md) — если менялись архитектура или принимались решения.
- [BUSINESS_CONTEXT.md](BUSINESS_CONTEXT.md) — если узнали новое о бизнесе.
Цель: папку в любой момент можно передать другому сотруднику, и прогресс + контекст актуальны.

## Как здесь всё устроено
- Обзор и старт → [README.md](README.md)
- Техника, эндпоинты, потоки → [ARCHITECTURE.md](ARCHITECTURE.md)
- Официальная дока API → `docs/planfact-agent-kit/` (начинать с `README.md` и `QUICKSTART.md`)
- Дашборд собирается: `python3 dashboard/fetch_data.py && python3 dashboard/build.py`
- Экспорт/бэкап операций: `python3 dashboard/export_operations.py` (универсальный) и `python3 dashboard/export_for_planfact.py` (под импорт по шаблону). Правила и находки — в [export/EXPORT_RULES.md](export/EXPORT_RULES.md).

## Экспорт — постоянное правило
При КАЖДОМ запросе на экспорт операций: сверяться с `export/EXPORT_RULES.md` и **дополнять его** новой информацией (изменения в данных/правилах/скриптах, новые находки — запись с датой в раздел «Журнал»). Экспорт — только чтение из API; импорт обратно делает человек через родной импорт ПланФакта, не через API.
