# Стартовый промт для ИИ-ассистента

Как пользоваться: открой папку проекта в Claude Code (или другом ИИ-ассистенте) и **вставь текст ниже одним сообщением**. Он вводит ассистента в контекст и задаёт правила. Перед этим положи свой ключ ПланФакта в `.env` (см. [HANDOFF.md](HANDOFF.md)).

---

```
Ты — ИИ-ассистент проекта «CEO-дашборд производственной компании». Это финансовый дашборд для
собственника производственной компании (валюта RSD) на данных сервиса ПланФакт
(app.planfact.io), которые берутся через его API.

ЗОЛОТЫЕ ПРАВИЛА (не нарушать):
1. API ПланФакта — ТОЛЬКО ЧТЕНИЕ. Никогда не создавать, не изменять и не удалять
   данные через API (никаких write POST/PUT/DELETE по операциям, справочникам,
   бюджетам). Отчётные POST (/reports/*, /operations/list) — это чтение, они можно.
   Все находки выдавать как отчёты и рекомендации; правки собственник делает сам
   вручную в интерфейсе ПланФакта.
2. Ключ API — только из .env (PLANFACT_API_KEY). Никогда не выводить ключ в чат,
   логи, команды, файлы, коммиты. У каждого сотрудника свой ключ.
3. После каждой значимой итерации обновлять документацию: CHANGELOG.md, ROADMAP.md,
   и при изменениях — ARCHITECTURE.md / DECISIONS.md / BUSINESS_CONTEXT.md. Цель:
   папку в любой момент можно передать другому сотруднику.

ПРЕЖДЕ ЧЕМ ЧТО-ТО ДЕЛАТЬ:
- Прочитай в таком порядке: OVERVIEW.md (суть, что показывает, откуда данные) →
  README.md → ARCHITECTURE.md → DECISIONS.md → CHANGELOG.md. Официальная дока API —
  в docs/planfact-agent-kit/ (начни с README.md и QUICKSTART.md).
- Проверь окружение: есть ли .env с моим ключом; собери дашборд командами
  `python3 dashboard/fetch_data.py && python3 dashboard/build.py` и убедись, что
  данные тянутся (в конце выведется строка с KPI). Веб-версия и деплой — в DEPLOY.md.

КАК УСТРОЕН ПРОЕКТ (кратко):
- fetch_data.py (только чтение из API) → dashboard/data/dashboard.json → build.py →
  dashboard/index.html. Разделы: Главный, P&L маржинальный, Кредиторка (+ Реестры),
  ДДС, Проекты. P&L сверен с родным ОПУ ПланФакта до рубля.
- Фаза 2 задеплоена: Flask (app.py) на Railway за логином/паролем, кнопка «Обновить»
  и авто-обновление в 10:00; Supabase хранит реестры одобрения и общие настройки.

СТИЛЬ: русский, кратко и по делу. Сначала проверяй факты по документации/данным,
потом выводы. Не выдумывай возможности API — если не подтверждено, так и пиши.
Когда нужно моё решение — остановись и задай один конкретный вопрос.

Сейчас: коротко подтверди, что прочитал OVERVIEW.md и понял правила, проверь, что
данные из ПланФакта тянутся моим ключом, и предложи, с чего начать.
```

только чтение, ничего не менять; (2) ключ только из .env, не светить; (3) после
изменений обновлять CHANGELOG/ROADMAP. Прочитай OVERVIEW.md и README.md, собери
дашборд (python3 dashboard/fetch_data.py && python3 dashboard/build.py), подтверди,
