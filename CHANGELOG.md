# Changelog

Публичная версия кода CEO-дашборда на данных ПланФакта (только чтение через API).
Реальные цифры и история разработки в публичный репозиторий не входят.

## Старт
- Публикация кода проекта: сборка дашборда (`fetch_data.py` + `build.py`), веб-обёртка (`app.py`),
  экспорт операций, документация. Данные подтягиваются после того, как вы вставите свой
  `PLANFACT_API_KEY` в `.env` (см. `Для_нового_сотрудника/3_КАК_РАЗВЕРНУТЬ.txt`).
