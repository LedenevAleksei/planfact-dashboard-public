# PlanFact CEO Dashboard

Проект: аналитика и CEO-дашборд для производственной компании на данных сервиса **ПланФакт** (app.planfact.io) через его API.

> ⚠️ **Главное правило: работа с API ПланФакта — ТОЛЬКО ЧТЕНИЕ.** Никогда не создавать, не изменять и не удалять данные через API. Все находки — в виде отчётов и рекомендаций; исправления пользователь делает вручную в интерфейсе ПланФакта. Подробнее → [DECISIONS.md](DECISIONS.md).

## Что это

1. **CEO-дашборд** (папка `dashboard/`) — веб-панель с меню (Главный / P&L маржинальный / Кредиторка + Реестры / ДДС / Проекты), обновляется из ПланФакта. Задеплоен как веб-сервис за логином/паролем (Фаза 2, Railway) — см. [DEPLOY.md](DEPLOY.md).
2. **Разовые отчёты** (папка `reports/`) — HTML-отчёты: расходы, продажи (начисление vs касса), реестры дебиторки/кредиторки по неделям, гигиена данных, справка по формату импорта ПланФакта.

> 📖 **Что дашборд показывает и откуда берутся данные — в [OVERVIEW.md](OVERVIEW.md) (мини-документация).** Новому сотруднику: [HANDOFF.md](HANDOFF.md) + стартовый промт [STARTER_PROMPT.md](STARTER_PROMPT.md).

## Быстрый старт

1. Установить свой API-ключ ПланФакта (Настройки → Мой профиль в app.planfact.io):
   ```
   cp .env.example .env
   # вписать свой ключ в .env: PLANFACT_API_KEY=...
   ```
2. Собрать дашборд:
   ```
   python3 dashboard/fetch_data.py    # выгрузка данных из ПланФакта (только чтение)
   python3 dashboard/build.py         # рендер dashboard/index.html
   ```
3. Открыть `dashboard/index.html` в браузере.

Зависимости: только стандартный Python 3 (без внешних пакетов).
