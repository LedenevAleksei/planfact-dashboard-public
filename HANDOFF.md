# Онбординг нового сотрудника

Этот проект передаётся как папка. Ниже — что сделать, чтобы начать работу.

## 0. Где лежит код — папка или GitHub?
Проект — **самодостаточная папка** (~3,6 МБ, только стандартный Python 3, без внешних пакетов). **Весь код внутри папки. Подключаться к чужому GitHub не обязательно.**

Три способа получить проект:
- **A. Просто папка** (zip/копия) — проще всего. Работаешь локально, GitHub не нужен.
- **B. Доступ к репозиторию владельца** — если нужна общая история версий (тебя добавят Collaborator'ом в приватный репозиторий).
- **C. Свой репозиторий** — перепривязать `origin` на свой и пушить.

Нюансы:
- Для локальной работы (собрать и открыть дашборд) GitHub **не нужен вообще** — достаточно папки + своего ключа.
- Если получил папку как есть, в ней `.git` привязан к GitHub прежнего владельца. Убери привязку: `git remote remove origin` (или удали папку `.git`, если история не нужна).
- **Живая веб-версия (Railway)** деплоится из папки командой `railway up`, не привязана к GitHub. Чтобы обновлять прод — нужен доступ к Railway (см. [DEPLOY.md](DEPLOY.md)), а не к GitHub.

## 1. Получить свой API-ключ ПланФакта
1. Зайти в app.planfact.io → Настройки → **Мой профиль**.
2. Скопировать/выпустить свой **API-ключ (ApiKey)**.
3. Ключ — как пароль: не пересылать в мессенджерах/чатах, не коммитить.

> Ключ предыдущего сотрудника вам не передаётся и не нужен. У каждого — свой.

## 2. Настроить .env
```
cp .env.example .env
```
Открыть `.env` и вписать свой ключ:
```
PLANFACT_API_KEY=ваш_ключ
```
Файл `.env` уже в `.gitignore` — он не попадёт в git и не должен передаваться.

## 3. Проверить окружение
- Нужен только Python 3 (проверить: `python3 --version`). Внешних пакетов нет.
- Проверить подключение и собрать дашборд:
```
python3 dashboard/fetch_data.py
python3 dashboard/build.py
```
- Открыть `dashboard/index.html` в браузере.

Если `fetch_data.py` ругается на `.env` — значит ключ не задан (шаг 2). Если API вернул ошибку доступа — проверить, что ключ действующий и тариф позволяет чтение отчётов.
